# Dark screen app
#### A screen-dimming app for those times when even the minimum brightness is still too glaring.

## Peculiarities:
1. Dims the screen
2. Brightness reduction slider
3. No ads or donations
4. It’s lightweight and doesn’t put a load on the system

## Technical specifications:
1. SDK: min 16 (android 4.1), max 35
2. Approximate weight (including optimization): ~30 KB
3. Language: Java, XML
